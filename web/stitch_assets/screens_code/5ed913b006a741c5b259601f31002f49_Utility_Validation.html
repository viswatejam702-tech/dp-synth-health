TSTR (Train-Synthetic-Test-Real) Protocol

Evaluating the downstream utility of differentially private synthetic data against a holdout set of real patient records. The goal is to measure the utility decay introduced by the privacy budget (ε).

Validation Config (GBDT)


# DP-XGBoost Parameters
xgb_params = {
    'max_depth': 4,
    'learning_rate': 0.05,
    'n_estimators': 150,
    'privacy_budget': 0.85,
    'tree_method': 'hist',
    'objective': 'binary:logistic',
    'eval_metric': 'auc'
}

# TSTR Evaluation Pipeline
evaluator = TSTREvaluator(
    models=[xgb_clf, rf_clf, lr_clf],
    metrics=['auc', 'f1', 'accuracy']
)
results = evaluator.run(syn_train, real_test)

insights Key Insights

  • Utility decay is primarily observed in tail-end distributions.
  • At ε=0.85, the AUC drop is ~0.08 compared to real data.
  • Gradient Boosting maintains the most resilience to noise injection.
